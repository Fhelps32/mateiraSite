# Física Experimental · Guia de Estudo

Site em React (Vite) com a matéria do caderno, organizada por tópicos, com
fórmulas, figuras, calculadoras e perguntas de autoteste.

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/
```

## Adicionando matéria nova

Todo o conteúdo fica em `src/content/topics.js`. Basta acrescentar um objeto ao
array `topics` (os tipos de bloco disponíveis estão descritos no topo do arquivo).
